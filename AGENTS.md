## If AI did the work, say so

Include an `Assisted-By: {agent}:{model}` commit trailer when an AI agent materially contributes code, tests or documentation.
Do not include it when the agent did not contribute significant code, such as when it was used to discuss architecture, consult documentation, or trivially complete code automatically.
