# Architecture Decisions

This directory contains Architecture Decision Records (ADRs) which explain the rationale behind the most significant aspects of VAIPE's design.

ADRs are added when implementation is about to depend on a significant
decision and that decision should be justified and recorded.

## Status Meanings

- **proposed**: being considered, but not yet official project policy,
- **accepted**: currently part of VAIPE's architecture,
- **superseded**: replaced by a later ADR,
- **rejected**: considered but explicitly not adopted.
